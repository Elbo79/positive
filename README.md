# Reinforcement Coach Android App

A native Android app that provides:
- Four truthful reinforcement statements
- Coaching questions
- A 30-second frustration reset
- Daily local notifications
- On-device constructive-pause tracking
- Offline operation

## Build APK automatically on GitHub
1. Create a new public or private GitHub repository.
2. Upload every file and folder from this project to the repository root.
3. Open the repository's **Actions** tab.
4. Open **Build Android APK**.
5. Click **Run workflow**.
6. When the run finishes, open it and download the **Reinforcement-Coach-APK** artifact.
7. Unzip the artifact and install `app-debug.apk` on your Android phone.

Android may ask you to allow installation from your browser or Files app. Enable that only for the app you are using to open this APK, install it, and then turn the permission back off if preferred.
