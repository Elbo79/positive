# Positive Compass Flutter v0.3.0

This folder contains the Family Compass feature for the Flutter version of Positive Compass. The repository root contains a separate legacy Android project; do not replace it.

Download the complete v0.3.0 Flutter source ZIP from the ChatGPT conversation to install it into your existing working Flutter project. This GitHub folder records the new coaching practice source and integration details.

New practices: Be a Safe Place (listen, connect, ask, repair) and Build Confidence (connect without correcting, notice real effort, ask questions, value courage). Reflection text is not persisted.
